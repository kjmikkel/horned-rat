# horned-rat

An unofficial patch (and, eventually, possibly a source port) for the 1995 Windows
release of *Warhammer: Shadow of the Horned Rat*.

**This repository contains no game assets or original binaries.** A legally
obtained copy of the game (e.g. the GOG release) is required to use anything here.

## Goals (in priority order)

1. Make the game run well on modern Windows — first and foremost a larger,
   properly scaled display instead of the fixed 640×480 window.
2. Improve the game itself: AI and pathfinding, bug fixes, UI pain points,
   mod support, quality-of-life features (e.g. moving magic items between units).
3. Other platforms (nice to have).
4. Documentation of the game's internals and file formats.

## Status

Planning. See `docs/` as the design takes shape.
